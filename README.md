# 🌿 Minimalist

Modern and clean web application built with React, Tailwind CSS, and Vite.

🔗 Live Demo: https://minimalist-lime-eight.vercel.app/

<img width="953" height="494" alt="minimalist" src="https://github.com/user-attachments/assets/5da62d5b-00bb-410a-bb95-6645d2e1a462" />


## ✨ Features

- 📱 **Fully responsive** design optimized for all screen sizes
- 🎨 **Minimalist UI** focus on clean aesthetics and user experience
- ⚡ **Fast & lightweight** performance powered by Vite
- 🧩 **Modular component architecture** for clean code structure
- 🔄 **Dynamic layout rendering** and smooth interactions

## 🛠️ Tech Stack

- **React + Vite**
- **Tailwind CSS**
- **JavaScript (ES6+)**
- **HTML5 & CSS3**

## 🚀 What I Learned

- Building responsive UI layouts with Tailwind CSS
- Managing component-driven architecture in React
- Modern build tooling and deployment with Vite and Vercel
- Clean code practices and UI/UX optimization
